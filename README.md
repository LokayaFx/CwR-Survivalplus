# 🚀 CWR Survivalplus

Welcome to **CWR Survivalplus** – the ultimate client-side optimization pack tailored specifically for the **CwR Survival**! 

This pack features **55 performance-focused mods** designed to do one thing perfectly: give you the absolute highest FPS and lowest ping possible on the server, while keeping essential cosmetic and voice features working flawlessly.

---

## 🔥 Key Features & Mod Breakdown

### 🏎️ Hardcore Performance Optimization
Engineered to eliminate lag spikes and frame drops around spawn, custom shops, and heavy player areas:
* **Sodium & Sodium Extra:** Next-gen rendering for massive FPS boosts.
* **Lithium & FerriteCore:** Optimizes memory usage, chunk physics, and reduces RAM consumption.
* **ModernFix & BadOptimizations:** Fixes engine-level memory leaks and hidden background bottlenecks.
* **ImmediatelyFast & EntityCulling:** Speeds up HUD text rendering and stops rendering hidden entities/blocks to save GPU power.
* **C2ME & VMP:** Optimizes chunk loading and network packets to reduce multiplayer network lag.

### 🎙️ CWR Server Feature Compatibility
Ensures all custom server elements and player interactions look and work perfectly:
* **Cosmetica & 3D Skin Layers:** Displays custom cosmetics, capes, and breaks player skins into enhanced 3D layers.
* **Entity Model/Texture Features:** Fixes custom texture and entity model bugs on multiplayer servers.

### 📊 Clean HUD & Smooth Tweaks
* **Ukus Armor HUD & StatusEffectTimer:** Minimalist armor durability and active potion effect timers on your screen.
* **Appleskin:** Displays precise food saturation directly on your hunger bar.
* **Gamma Utils:** Built-in Fullbright utility for clean visibility in dark areas.
* **Zoomify:** Lightweight, smooth cinematic zoom.
